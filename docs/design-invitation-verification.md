# 팀 관리와 초대 디자인 검증

2026년 11월 19일

## 반영 범위

- Figma 스크린샷과 속성에서 팀 관리 560px, 초대 600px, 참여 760px 규격 확인
- 팀 관리 여백 32px, 모서리 16px, 제목 24px, 팀원 사이 간격 24px 적용
- 팀원 초대와 소유자 변경을 별도 행으로 배치
- 초대 링크, 설명, 복사 버튼 순서를 맞추고 만료와 재발급 영역 유지
- 홈에서 링크를 입력하고 같은 모달에서 프로젝트 정보를 확인한 다음 명시적으로 참여
- 외부 초대 경로와 로그인 및 가입 후 복귀 경로 유지
- 모달의 종료 전환과 기본 키보드 동작 유지, 모달 내부 화면 변경 시 포커스 보완

## 실제 서버와 브라우저

Chrome에서 localhost:5174와 localhost:8081 연결

- 1440x900에서 팀 관리, 팀원 초대, 프로젝트 참여 모달을 Figma 스크린샷과 비교
- 실제 프로젝트의 팀원 목록, 링크 발급, 복사 성공과 만료 시간 확인
- 홈 링크 입력 모달에서 실제 초대 정보 확인 후 명시적인 버튼으로 참여 중인 프로젝트 열기 확인
- 390x900에서 팀 관리 모달의 제목, 팀원, 초대 및 소유자 변경 버튼 접근 확인
- 프로젝트 화면에서 팀 관리 버튼으로 열 때 닫기 버튼에 포커스 이동
- Tab으로 팀원 초대 버튼 이동, Esc로 닫은 후 팀 관리 버튼에 포커스 복귀

## 모킹 검증

- 초대 확인만으로 가입하지 않음
- 링크 변경 시 이전 프로젝트의 참여 버튼 제거
- 다른 출처의 링크 거부
- 익명 사용자의 로그인 복귀와 가입 미완료 사용자의 프로필 복귀 경로
- 클립보드 거부 시 직접 복사 안내, 링크 재발급 후 이전 상태 초기화
- 팀 관리 모달을 다시 열면 이전 초대 화면을 유지하지 않고 목록으로 복귀
- 접근 권한 회수, 저장하지 않은 입력 보존과 소유권 이전의 기존 회귀 테스트 유지

새 계정의 실제 로그인 및 가입 후 초대 복귀, 모션 줄이기 에뮬레이션은 통합 검증에서 추가 기록한다
