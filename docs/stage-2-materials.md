# 자료 화면 구현

## 구현 범위

### 자료 목록과 상세, 팀 메모

- 경로 `/projects/:projectId/materials`와 탐색기의 자료 탭
- 검색어, 유형 필터, 선택한 자료를 주소에 둔다. 검색어 입력은 250ms 뒤에 반영하고 기록을 쌓지 않는다
- 이전 검색의 늦은 응답은 버린다. 새 검색을 불러오는 동안 입력란과 이전 목록을 그대로 둔다
- 자료 없음, 검색 결과 없음, 처리 중, 분석 실패, 준비 완료를 구분한다
- 분석 실패는 보관한 원본으로 다시 시도한다. 결과를 모르는 재시도는 같은 멱등 키를 다시 보낸다
- 이름 변경은 버전을 비교하고 충돌하면 입력을 남긴다
- 삭제는 서버가 알려 준 삭제 가능 여부로 막고 서버의 거절도 안내한다. 이미 삭제된 응답은 삭제된 것으로 본다
- 팀 메모는 버전 충돌 때 내 입력을 남기고 사용자가 고른 뒤에만 덮어쓴다. 응답을 못 받으면 다시 읽어 내 입력과 같을 때 저장된 것으로 본다
- 팀 메모를 쓰는 중에 다른 자료나 다른 화면으로 옮기면 확인한다. 검색과 필터는 입력을 잃지 않아 막지 않는다
- 접근 권한이 사라지면 화면의 자료 내용을 지우고 안내한다

발표 구성 보기 버튼과 발표에 연결된 위치 영역은 발표 구성 단계에서 만든다.

### 자료 추가

- 자료 추가 모달에서 PDF, 링크, 마크다운 자료를 추가하고 기존 마크다운 자료를 고친다
- PDF는 기능 지원 정보의 형식과 크기로 먼저 확인하고 파일 확인, 업로드 준비, 파일 전송, 자료 등록 단계를 따로 표시한다
- 파일 전송에는 발급받은 헤더만 싣는다. CSRF 헤더를 싣지 않는다
- 실패한 단계부터 다시 이어 간다. 전송을 마친 파일은 다시 올리지 않고 결과를 모르는 등록은 같은 멱등 키와 본문으로 다시 보낸다
- 업로드 실패는 모달의 실패 안내로, 분석 실패는 등록된 자료의 상세에서 알린다. 분석은 모달을 닫아도 계속된다
- 전송 중에 닫기를 누르면 전송만 멈추고 선택한 파일은 남긴다
- 링크는 주소 형식을 먼저 확인하고 서버가 거절한 주소는 입력란에 알린다. 실패해도 주소와 설명을 남긴다
- 마크다운은 작성과 미리보기를 오가도 입력란을 그대로 두고 원시 HTML은 그리지 않는다
- 메모를 쓰다가 닫거나 입력 유형을 바꾸면 확인한다. 계속 작성을 고르면 쓰던 입력란과 커서로 돌아가고 버리기를 골라야 지운다
- 마크다운 자료 수정은 버전을 비교한다. 충돌하면 내 입력을 남기고 고른 뒤에만 덮어쓴다
- 자료 화면은 들어갈 때 불러와 첫 화면의 묶음 크기를 유지한다

## 검증

자동 테스트는 실제 요청 클라이언트에 자료 모킹 서버를 연결해 화면을 조작한다. 모킹 검증이며 실제 서버 연동 검증이 아니다.

## 실제 서버로 확인할 것

- 자료 목록과 상세, 이름 변경, 삭제, 팀 메모의 요청과 응답 전부
- 소유자, 작성자, 다른 팀원, 참여하지 않은 사용자의 삭제와 접근 차이
- 팀원 제거 뒤 열려 있던 화면과 기존 주소의 접근 차단
- 실제 분석 작업의 처리 중, 실패, 완료 전환과 다시 시도
- 실제 PDF의 업로드 준비, 전송, 등록과 서버의 크기, 체크섬, 형식 검사
- 응답을 잃은 등록 요청을 같은 키로 다시 보냈을 때 자료와 작업이 하나만 만들어지는지
- 실제 링크 수집의 성공과 실패, 내부망 주소 거절
- 마크다운 자료의 저장과 재조회, 두 사용자의 수정 충돌
- 실제 한글 입력기로 메모와 팀 메모를 조합 중에 저장했을 때의 입력값
