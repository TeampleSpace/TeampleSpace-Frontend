# 프로젝트와 팀 관리

## 구현 범위

- 참여 중인 프로젝트 목록, 검색, 커서 기반 추가 조회
- 이름과 발표 주제 및 조건을 입력하는 프로젝트 생성
- 생성 응답이 불확실할 때 같은 멱등 키와 본문으로 결과 확인
- 프로젝트 기본 정보, 소유자만 가능한 저장과 이름 확인 후 삭제
- 팀원 목록, 소유권 이전, 팀원 제거와 본인 나가기
- 초대 링크 발급과 갱신, 복사 실패 시 직접 선택 안내
- 로그인과 가입 동의 뒤 초대 화면 복귀, 명시적으로 참여한 뒤 프로젝트 열기
- 권한 회수 응답 후 기존 프로젝트 화면과 탐색기 정보 숨김
- 화면 복귀와 주기적 조회로 권한 및 프로젝트 정보 재확인
- 미저장 설정이 있는 화면에서 이동과 새로고침 확인

공통 입력창과 모달을 사용하며 발표 정보는 여러 줄 입력과 한글 입력을 지원한다
현재 단계의 프로젝트 상세 화면은 기본 정보와 팀 관리만 제공한다
자료 편집과 발표자료 편집 기능은 후속 단계에서 연결한다

## 인증 기능 의존성

이 브랜치는 같은 저장소의 인증 PR 33 변경을 포함한다
두 PR은 main을 대상으로 하며 인증 PR이 먼저 병합되어야 한다
계약 복사본은 contracts-source.json에 명시한 원본 커밋에 고정했다
계약 전체의 파일 비교와 예제 스키마 검증을 모두 실행한다

## 검증 범위

프로젝트 생성의 불확실한 응답 이후 재시도, 초대의 명시적 참여, 익명 사용자의 복귀 경로와 일반 팀원의 제한된 설정 UI는 jsdom의 React 상호작용으로 검증한다
API 테스트는 CSRF, 멱등 키, 기준 버전과 팀원 제거 명령을 검증한다
이 테스트의 서버 응답은 모킹이며 실제 브라우저와 서버 왕복 검증은 아니다
현재 환경에서 Java 서버가 포트를 열 수 없어 실제 서버를 연결한 두 계정 초대 시나리오는 확인하지 못했다

실제 한글 입력은 사용자가 가능하다고 알려 준 결과와 자동 조합 이벤트 검증을 구분해 기록한다
실제 메일 전달, 소셜 제공자 왕복과 운영 약관 설정도 별도 확인 대상이다

## 최종 검증 기록

2026-11-18, Node 24.20.0에서 린트와 운영 빌드, 전체 테스트 83건과 원본 계약 전체 비교를 통과했다
생성 요청의 네트워크 실패와 서버 오류를 각각 재현해 재시도 시 멱등 키와 본문이 유지되는지 확인했다
