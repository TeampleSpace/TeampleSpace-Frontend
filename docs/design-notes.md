# 디자인 기준 기록

공통 스타일과 기본 UI를 피그마의 어떤 화면에서 읽었는지, 어떤 값을 반영했는지, 자료끼리 서로 다른 부분이 무엇인지 남기는 문서다.

## 기준

피그마 Product Design 파일의 제품 화면을 기준으로 한다. 2026-11-18에 아래 화면과 컴포넌트를 읽었다.

| 대상 | 피그마 노드 | 반영한 곳 |
| --- | --- | --- |
| 프로젝트 생성 모달 | 219:4306 | 입력 모달, 입력창, 버튼 |
| 프로젝트 삭제 확인 모달 | 219:6669 | 확인 모달, 삭제 버튼 |
| 요청 제한과 일시 오류 안내 모달 | 219:7716 | 안내 모달, 안내 줄 |
| 찾을 수 없음 화면 | 219:7647 | 가운데 안내 문구, 텍스트 버튼 |
| 버튼 컴포넌트 | 6:30 | 올림, 누름, 비활성 상태의 색 |
| 입력 컴포넌트 | 6:56 | 포커스, 오류, 비활성 상태 |

## 자료끼리 서로 다른 부분

제품 화면을 따랐다. 디자인 쪽에서 어느 것이 맞는지 확인이 필요하다.

| 항목 | 한쪽 | 다른 쪽 | 따른 것 |
| --- | --- | --- | --- |
| 주요 버튼 높이 | 프론트엔드 설계서 48px | 피그마 화면 44px | 피그마 화면 |
| 페이지 제목 줄높이 | 프론트엔드 설계서 40px | 피그마 화면 38px | 피그마 화면 |
| 보조 버튼 | 피그마 버튼 컴포넌트는 테두리 #E4E3DF, Medium 14/20 | 피그마 화면은 테두리 #7F8997, SemiBold 15/22 | 피그마 화면 |
| 입력창 | 피그마 입력 컴포넌트는 회색 면, 테두리 없음, 모서리 12px, 값 16/24 | 피그마 화면은 흰 면, 테두리 #7F8997, 모서리 8px, 값 16/26 | 피그마 화면 |
| 모달 배경 농도 | 프로젝트 생성 모달 36% | 삭제 확인과 안내 모달 32% | 32% |
| 버튼 누름 상태 | 피그마 버튼 컴포넌트의 누름 상태는 이전 글꼴과 높이 48px로 남아 있음 | 다른 상태는 현재 글꼴과 높이 | 색만 반영 |

## 피그마에서 확인하지 못한 것

- 불러오는 중 표시와 진행 표시 모양
- 여러 줄 입력창. 삭제 확인 모달의 이름 입력이 여러 줄 입력 컴포넌트인데 지금은 한 줄 입력창으로 대신했다
- 삭제 버튼의 올림과 누름 상태
- 프로젝트 탐색기가 있는 화면 틀과 아이콘. 다음 단계에서 만든다

편집 실험 화면과 파일 출력 비교 기준 화면은 개발용이라 피그마 화면을 따르지 않았다. 실제 편집 화면은 이후 단계에서 피그마를 기준으로 만든다.
