# 홈과 프로젝트 탐색 디자인 검증

2026년 11월 19일

## 반영 범위

- 최신 Figma 제품 화면의 1440x900 스크린샷과 레이아웃 속성을 직접 확인
- 사이드바 264px, 홈 여백 48px, 소개 배너 144px, 시작 카드 240px, 프로젝트 카드 312px 적용
- 프로젝트가 없는 홈, 프로젝트가 있는 홈, 검색 결과 없음 화면 분리
- 홈에서도 실제 프로젝트 목록과 팀 관리 및 설정에 접근 가능
- 자료와 슬라이드 편집은 준비 중으로 표시하고 동작하는 버튼을 만들지 않음
- 로그인과 공유 인증 레이아웃의 컴포넌트 및 애니메이션 유지
- 원본 Pretendard와 Gmarket Sans 폰트를 웹에서 제공하고 라이선스 포함
- 주요 콘텐츠에 180ms 페이드와 6px 이동 적용, 검색 결과 갱신에는 재등장 애니메이션을 적용하지 않음
- 모션 줄이기 환경에서는 기존 공통 규칙으로 애니메이션과 전환 제거

## 실제 서버와 브라우저

Chrome에서 localhost:5174 프론트엔드와 localhost:8081 백엔드를 연결해 확인

- 1440x900에서 빈 홈, 프로젝트가 있는 홈, 검색 결과 없음 화면을 Figma 스크린샷과 비교
- 새 프로젝트 모달에서 한글 이름으로 프로젝트 생성 성공, 프로젝트 개요 및 홈 목록 반영 확인
- 홈에서 프로젝트 목록, 팀 관리와 설정 링크 표시 확인
- 390x900에서 검색 입력, 안내와 검색 지우기 버튼이 가로 넘침 없이 표시되고 스크롤로 접근되는 것 확인

## 자동 검증

- Vitest 95개 통과, API 응답은 모킹이며 실제 서버 검증과 구분
- 검색 중 기존 카드와 입력 포커스 유지, 결과 없음 전환, 홈 사이드바 접근 테스트 추가
- 린트, TypeScript 검사와 프로덕션 빌드 통과

## 후속 검증

팀 관리, 초대 참여, 설정과 계정은 각 목적의 후속 PR에서 수정하고 검증한다
실제 소셜 로그인 재진입과 가입 후 초대 복귀는 초대 화면 수정 후 다시 확인한다
