# 프로젝트 설정과 내 계정 디자인 검증

2026년 11월 19일

## 반영 범위

- Figma 최신 화면의 스크린샷과 레이아웃 속성을 직접 확인
- 설정 본문 너비 760px, 요소 간격 24px, 안내 영역 여백 16px와 모서리 12px 적용
- 계정 입력 높이 56px, 요소 간격 20px, 로그인 수단 너비 560px 적용
- 프로젝트 삭제는 흰 배경과 테두리 및 빨간 글자, 탈퇴는 빨간 텍스트 버튼으로 구분
- 탈퇴 안내와 버튼을 같은 행에 두고 좁은 화면에서는 세로 배치
- 계정 화면에서 프로젝트 탐색과 관리 메뉴를 숨기고 홈으로 돌아오면 복원
- 기존 저장, 권한, 미저장 입력 보호, 로그아웃 및 재인증과 탈퇴 확인 동작 유지
- 로그인 화면과 공유 인증 레이아웃은 변경하지 않음

## 모킹 검증

로컬 연결이 끊기기 전 계정과 설정 스타일 변경에 대해 테스트 100개, 린트와 빌드가 통과했다
이후 계정 사이드바 표시 조건과 회귀 테스트를 추가했으므로 최종 커밋의 검증 결과는 PR CI에서 확인한다

API 모킹 테스트는 실제 서버 연동 검증을 대신하지 않는다

## 실제 서버와 브라우저

홈, 팀 관리와 초대 화면의 실제 브라우저 검증은 별도 문서에 기록했다
새 계정의 실제 백엔드 이메일 인증과 로컬 메일 수신, 이름 설정 및 약관 동의 이후 원래 초대 모달로 복귀하는 것을 확인했다
복귀 후 명시적인 참여 버튼이 표시되었으며 최종 참여 버튼은 아직 누르지 않았다

설정과 계정 화면은 로컬 실행 환경 연결이 끊겨 다음 항목을 완료하지 못했다

- 최종 수정본의 1440x900 및 좁은 화면 스크린샷 비교
- 실제 서버의 프로젝트 설정 저장과 계정 이름 저장
- 새 계정의 최종 프로젝트 참여
- 모션 줄이기 환경의 실제 브라우저 확인
- 카카오, 네이버, 구글을 통한 로그인 회귀 확인

이 PR은 위 검증을 마칠 때까지 초안으로 유지한다
