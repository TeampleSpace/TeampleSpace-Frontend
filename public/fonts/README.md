# 웹폰트

개발 환경에 설치되어 있던 원본 글꼴 파일을 수정하지 않고 배포한다
시스템 글꼴 유무와 관계없이 같은 글꼴을 내려받도록 local 선언은 사용하지 않는다

- Pretendard 1.309의 Regular, Medium, SemiBold, Bold, ExtraBold, Black
- Gmarket Sans TTF 1.000의 Bold
- Pretendard 라이선스는 공식 v1.3.9 배포본의 LICENSE를 함께 제공한다
- Gmarket Sans 라이선스는 원본 글꼴에 포함된 라이선스 전문을 함께 제공한다
- 파일 내부의 저작권과 라이선스 메타데이터도 유지한다

공식 배포처

- https://github.com/orioncactus/pretendard/tree/v1.3.9
- https://corp.gmarket.com/fonts/
